# Instagram Clone 📸

A responsive Instagram Clone built using **HTML, CSS, Bootstrap, and JavaScript**. This project replicates the basic user interface of Instagram, including the navigation bar, stories section, posts feed, and user profile layout.

## 🚀 Features

* Responsive Instagram-like UI
* Bootstrap-powered design
* Navigation Bar
* Stories Section
* Post Feed
* Like, Comment, and Share Icons
* User Profile Layout
* Mobile-Friendly Design
* Clean and Modern Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Bootstrap Icons
